# boumrank-next — Site web actif

Projet Next.js qui alimente la présence web de BoumRank (www/app). **C'est le projet de production.**

> Ce fichier est le README de navigation workspace. Le README technique du projet reste `README.md`.

## Statut

- **Actif** (réorganisation 2026-04-20)
- Remplace: `Boumrank website/` (Vite) et `FeednBack-website-2 repository/`, tous deux archivés dans `../_Archive/old-websites/`.

## Démarrage rapide

```bash
cd boumrank-next
npm install        # si pas déjà fait
npm run dev        # dev server
npm run build      # build prod
```

Déploiement: Vercel (via `vercel.json`).
